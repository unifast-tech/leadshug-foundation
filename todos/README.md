# LeadsHug TODOs

Todo desenvolvimento deve possuir um TODO ativo, criado a partir de `delphi-ai/templates/todo_template.md`.

Use `todos/active/features/` para capacidades, `todos/active/bugs-performance/<severity>/` para bugs e
performance, e `todos/active/backlog/` para ideias ainda não aprovadas. TODOs encerrados ficam em
`todos/completed/`. Um TODO só pode ser encerrado com
Definition of Done, validações e evidências específicas.
